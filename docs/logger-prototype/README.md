# Sensor Logger prototype (hosted copy)

A copy of the clickable prototype of the phone app, built in the logger's own repository (`docs/prototype/` there, made with `scripts/make_prototype.py`). That repository is private, so the copy is kept here to be hosted on GitHub Pages and installed on a phone:

`https://ambi1999.github.io/elder-activity-agent/logger-prototype/`

Open it on the phone, then in Chrome **⋮ → Add to home screen → Install**, or in Safari on an iPhone **Share → Add to Home Screen**. The data is fictional.

Do not edit these files here. After a change in the logger repository, copy `index.html`, `manifest.webmanifest`, `icon-192.png` and `icon-512.png` here again.
